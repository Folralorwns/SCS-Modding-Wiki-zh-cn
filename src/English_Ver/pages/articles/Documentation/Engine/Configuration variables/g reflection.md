# Documentation/Engine/Configuration variables/g reflection

|  |  |
| --- | --- |
| **Name:** | g_reflection |
| **Purpose:** | Reflection detail. |
| **Config:** | global |
| **Value:** | integer - reflection_detail |

## reflection_detail values:

| Value | Description |
| --- | --- |
| 0 | no reflection |
| 1 | water reflection only |
| 2 | vehicle reflection only |
| 3 | both water and vehicle reflections |
