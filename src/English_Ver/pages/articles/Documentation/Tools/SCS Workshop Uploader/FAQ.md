# Documentation/Tools/SCS Workshop Uploader/FAQ

- Q: I want to upload my map mod to the Workshop however I get many errors that .aux and other file formats are not supported. Help!
- A: In the initial release of the Steam Workshop implementation we do not support map mods. Maybe we will support them in the future.

- Q: I want to create a mod of type X however I don't see this type tag available. What to do?
- A: We do recommend using the tag "Others". However, we will add new tags over time.

- Q: The game was updated and my mod is not working anymore. How can I provide multiple versions of my mod to users on different versions?
- A: Steam Workshop mods allow you to support multiple game versions at once. Click [here](Workshop%20mod%20structure.md) to learn how.

- Q: I want to update my mod. How can I do this?
- A: As soon as you open SCS Workshop Uploader you will be able to choose a game and a mod published by you. Just select your mod folder, image and write a changelog. Click on "Upload" as you did initially and your mod will automatically be dispatched to all subscribers. Click [here](../../../Tutorials/SCS%20Workshop%20Uploader/How%20to%20update%20workshop%20mod_.md) to learn more.
