# Documentation/Tools/Map Editor/ATS Map Rescale

The editor background image for the new rescaled ATS map can be downloaded from [here](https://modding.scssoft.com/download/new_usa_editor_bcg.zip).

Note that for use in editor you need to convert the image from jpg to dds (or tga). Editor data files includes info about the map position in space.
