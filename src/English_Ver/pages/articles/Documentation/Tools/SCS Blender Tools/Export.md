# Documentation/Tools/SCS Blender Tools/Export

Beside exporting models from [Export Panel](Export%20Panel.md) you can export models from menu entry **SCS Game Object(s) (.pim)**. It features the same behaviour as export panel with exception that all files will be exported in selected directory.

[![SCS_Tools_Export_02.280.png](../../../../../../images/articles/Documentation/Tools/SCS%20Blender%20Tools/Export/SCS_Tools_Export_02.280.png)](../../../../files/SCS%20Tools%20Export%2002.280.png.md)

> > **Note:** Even if you can select different directory it still has to be inside current SCS Project Base Path otherwise it would be impossible to reconstruct relative texture paths.

## Export Options
