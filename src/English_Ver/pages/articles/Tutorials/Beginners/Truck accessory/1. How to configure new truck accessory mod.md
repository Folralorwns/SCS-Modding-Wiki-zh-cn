| **2** | [![Truck_accessory_create_base_and_ma.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/1.%20How%20to%20configure%20new%20truck%20accessory%20mod/Truck_accessory_create_base_and_ma.jpg)](../../../../files/Truck%20accessory%20create%20base%20and%20ma.jpg.md) | Inside **02_truck_accessory** create folders: **mod_accessory** - where you will put the new resources **base** - for existing game resources which you will use |
| **3** | [![Truck_accessory_create_def_tree.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/1.%20How%20to%20configure%20new%20truck%20accessory%20mod/Truck_accessory_create_def_tree.jpg)](../../../../files/Truck%20accessory%20create%20def%20tree.jpg.md) | Inside **mod_accessory** create folders: **def** **vehicle** **truck** **renault_mangnum** **accessory** **f_grill** |
| **4** | [![Truck_accessory_create_custom_g_sii.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/1.%20How%20to%20configure%20new%20truck%20accessory%20mod/Truck_accessory_create_custom_g_sii.jpg)](../../../../files/Truck%20accessory%20create%20custom%20g%20sii.jpg.md) | Inside **/02_truck_accessory/mod_accessory/def/vehicle/truck/renault_magnum/accessory/f_grill** create file called **custom_g.sii** which will contain definition of the grill. And paste there the following example definition: SiiNunit { accessory_addon_data : unit.name { name: "My front grill" price: 1 unlock: 0 icon: "f_grill_09" exterior_model: "model path" } } And keep the file opened. |
| **4** | [![Truck_accessory_definition_description.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/1.%20How%20to%20configure%20new%20truck%20accessory%20mod/Truck_accessory_definition_description.jpg)](../../../../files/Truck%20accessory%20definition%20description.jpg.md) | Now change definition as you want: "unit.name" must be set to some **unique** value - each component divided by dot can have **max 12 characters**. For example the good name will be **custom.amazing.renault.f_grill** The name is the name of the accessory in truck configuration screen. You can call it in any way. The price is a price of your accessory in game base currency (€ for ETS2, $ for ATS). The level when the accessory is unlocked. If zero it will be unlocked immediately on game start. The icon is a image that is displayed in truck configuration screen. We will leave the image at the moment as **f_grill_09**. The exterior_model is a model of the grill. It must a path to the **.pmd** file you will get after converting the data. So for this it will be: **"/vehicle/truck/upgrade/frontgrill/renault_magnum_2009/custom_grill.pmd"**. |
| **5** | [![Truck_accessory_create_vtufr.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/1.%20How%20to%20configure%20new%20truck%20accessory%20mod/Truck_accessory_create_vtufr.jpg)](../../../../files/Truck%20accessory%20create%20vtufr.jpg.md) | Inside **mod_accessory** create folders: **vehicle** **truck** **upgrade** **frontgrill** **renault_magnum_2009** |
| **7** | [![Truck_accessory_create_bme.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/1.%20How%20to%20configure%20new%20truck%20accessory%20mod/Truck_accessory_create_bme.jpg)](../../../../files/Truck%20accessory%20create%20bme.jpg.md) | Inside the **base** folder create folders: material environment |
| **6** | [![Truck_accessory_copy_basic_mats.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/1.%20How%20to%20configure%20new%20truck%20accessory%20mod/Truck_accessory_copy_basic_mats.jpg)](../../../../files/Truck%20accessory%20copy%20basic%20mats.jpg.md) | To the **environment** copy **generic_s.tga** and **vehicle_reflection.tobj** files from the **BlenderTools-1.2\data\sample_base\material\environment** folder which you can find in the folder where you extracted **SCS Blender Tools**. |
