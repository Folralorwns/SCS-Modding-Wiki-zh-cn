| --- | --- | --- |
| **1** | [![Truck_accessory_set_project_base_path.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/2.%20How%20to%20create%20model%20of%20front%20grill%20accessory/Truck_accessory_set_project_base_path.jpg)](../../../../files/Truck%20accessory%20set%20project%20base%20path.jpg.md) | Set **SCS Project Base Path** to root folder of the mod `02_truck_accessory/mod_accessory`. |
| **2** | [Watch on youtube](https://youtube.com/watch?v=q14zBnThXRg&t=33s) | Delete the default cube from the Blender scene and start modeling the front grill as shown on the video on the left. |
| **3** | [![Truck_accessory_create_empty.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/2.%20How%20to%20create%20model%20of%20front%20grill%20accessory/Truck_accessory_create_empty.jpg)](../../../../files/Truck%20accessory%20create%20empty.jpg.md) | Create **empty** blender object at the X: 0, Y: 0, Z: 0 coordinates. |
| **4** | [![Truck_accessory_change_empty_type_0.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/2.%20How%20to%20create%20model%20of%20front%20grill%20accessory/Truck_accessory_change_empty_type_0.jpg)](../../../../files/Truck%20accessory%20change%20empty%20type%200.jpg.md) | Navigate to the **Object Type** selection. |
| **5** | [![Truck_accessory_change_empty_type_1.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/2.%20How%20to%20create%20model%20of%20front%20grill%20accessory/Truck_accessory_change_empty_type_1.jpg)](../../../../files/Truck%20accessory%20change%20empty%20type%201.jpg.md) | Select object tzpe to **Locator**. |
| **6** | [![Truck_accessory_select_locator_type.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/2.%20How%20to%20create%20model%20of%20front%20grill%20accessory/Truck_accessory_select_locator_type.jpg)](../../../../files/Truck%20accessory%20select%20locator%20type.jpg.md) | In the locator **type** select **Model**. |
| **7** | [![Truck_accessory_name_locator.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/2.%20How%20to%20create%20model%20of%20front%20grill%20accessory/Truck_accessory_name_locator.jpg)](../../../../files/Truck%20accessory%20name%20locator.jpg.md) | Name locator as `slot_0`. |
| **8** | [![Truck_accessory_place_four_locators.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/2.%20How%20to%20create%20model%20of%20front%20grill%20accessory/Truck_accessory_place_four_locators.jpg)](../../../../files/Truck%20accessory%20place%20four%20locators.jpg.md) | Duplicate locators and place them as shown on the image. Also please call all the locators from left to right as. slot_0 slot_1 slot_2 slot_3 |
| **9** | [![Truck_accessory_add_root.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/2.%20How%20to%20create%20model%20of%20front%20grill%20accessory/Truck_accessory_add_root.jpg)](../../../../files/Truck%20accessory%20add%20root.jpg.md) | Create root object and call it the same way as you called in the definition file - so it will be `custom_grill`. |
| **10** | [![Truck_accessory_set_default_export_path.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/2.%20How%20to%20create%20model%20of%20front%20grill%20accessory/Truck_accessory_set_default_export_path.jpg)](../../../../files/Truck%20accessory%20set%20default%20export%20path.jpg.md) | Set **default export path** to location defined inside **custom_g.sii** file created in the previous tutorial. If you did everything as shown in the tutorial it should be `//vehicle/truck/upgrade/frontgrill/renault_magnum_2009`. |
| **11** | [![Truck_accessory_export.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/2.%20How%20to%20create%20model%20of%20front%20grill%20accessory/Truck_accessory_export.jpg)](../../../../files/Truck%20accessory%20export.jpg.md) | Set **mod** directory path. Set **mod name**. Enable **Auto Clean**, **Auto Export** and **Auto Conavert** options and set compression format to **Deflated**. Start conversion and packing of the mod by clicking on **PACK CONVERTED DATA** button. |
