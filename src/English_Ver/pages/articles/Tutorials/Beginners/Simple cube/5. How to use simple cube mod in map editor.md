# Tutorials/Beginners/Simple cube/5. How to use simple cube mod in map editor

> [← Previous part](4.%20How%20to%20convert%20&%20pack%20a%20mod.md)
>
> [All steps](../Simple%20cube.md)

|  |  |  |
| --- | --- | --- |
| **1** | [![Simple_cube_ensure_console.jpg](../../../../../../images/articles/Tutorials/Beginners/Simple%20cube/5.%20How%20to%20use%20simple%20cube%20mod%20in%20map%20editor/Simple_cube_ensure_console.jpg)](../../../../files/Simple%20cube%20ensure%20console.jpg.md) | Open **config.cfg** file from home directory of the game. And ensure that **g_console** and **g_minicon** are set to **"1"**. See [Game user path](../../../Documentation/Engine/Game%20user%20path.md) where you can find the **config.cfg** file on your computer. |
| **2** | [![Simple_cube_console.jpg](../../../../../../images/articles/Tutorials/Beginners/Simple%20cube/5.%20How%20to%20use%20simple%20cube%20mod%20in%20map%20editor/Simple_cube_console.jpg)](../../../../files/Simple%20cube%20console.jpg.md) | Start the game and select tilde button on the keyboard **[~]**. When you do it the game console should appear. Type **edit** command to start map editor. |
| **3** | [![Simple_cube_select_item_type.jpg](../../../../../../images/articles/Tutorials/Beginners/Simple%20cube/5.%20How%20to%20use%20simple%20cube%20mod%20in%20map%20editor/Simple_cube_select_item_type.jpg)](../../../../files/Simple%20cube%20select%20item%20type.jpg.md) | Change **item type** to **model**. |
| **4** | [![Simple_cube_select_place_tool_and_select_model.jpg](../../../../../../images/articles/Tutorials/Beginners/Simple%20cube/5.%20How%20to%20use%20simple%20cube%20mod%20in%20map%20editor/Simple_cube_select_place_tool_and_select_model.jpg)](../../../../files/Simple%20cube%20select%20place%20tool%20and%20select%20model.jpg.md) | Select **item creation** mode by clicking the green **+** icon (**1**). The item creation window will appear select the model you want to create (**2**) in our case it will be **simple_cube/simple_cube.pmd**. Place the model into the world by clicking **left mouse button** and close item creation dialog by clicking on it and clicking **Escape** button on keyboard. Change camera to **bird camera** using **C** key on keyboard and fly to your box to see it in game. |
| **5** | [![Simple_cube_box_in_world.jpg](../../../../../../images/articles/Tutorials/Beginners/Simple%20cube/5.%20How%20to%20use%20simple%20cube%20mod%20in%20map%20editor/Simple_cube_box_in_world.jpg)](../../../../files/Simple%20cube%20box%20in%20world.jpg.md) | Congratulations. Your own model can be placed on the map in game. Good job! |
