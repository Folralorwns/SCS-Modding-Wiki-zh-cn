So far, we should have a basic road made up of a few nodes. We have moved our road pieces around to give ourselves a nice curve, but it's looking a bit weird. How do we solve this problem? We can use free rotation to fix the angels generated between nodes giving us smoother turns as well as allowing a few other unique opportunities.

|  |  |  |
| --- | --- | --- |
| **1** | [![Node_properties.jpg](../../../../../../images/articles/Tutorials/Map%20Editor/Roads/Road%20Node%20Manipulation/712px-Node_properties.jpg)](../../../../files/Node%20properties.jpg.md) | Click on Node properties (*N Key*) Click the bottom most node on our road connection from the previous tutorial Check Free rotation checkbox In the Yaw box type 0 for 0 degrees |
| **2** | [![Nice_road_curve_90d.jpg](../../../../../../images/articles/Tutorials/Map%20Editor/Roads/Road%20Node%20Manipulation/712px-Nice_road_curve_90d.jpg)](../../../../files/Nice%20road%20curve%2090d.jpg.md) | Click the top most node and do the same except you will use a Yaw of 90 degrees |
| **3** | [![Road_angles_gizmo_circle.jpg](../../../../../../images/articles/Tutorials/Map%20Editor/Roads/Road%20Node%20Manipulation/712px-Road_angles_gizmo_circle.jpg)](../../../../files/Road%20angles%20gizmo%20circle.jpg.md) | Use the Move tool (*M Key*) to click the nodes and straighten our roads out for a nice 90 degree curve <br> <br> **TIP:** If you need to improve the angels even more you can add more nodes between the start and end nodes. Hit Middle mouse button while over a red node to create a new node between the node you clicked and the other end (*highlighted in blue*) <br> <br> **TIP:** Try switching the `Gizmo` to 'Circle' and use that to make nice curves even faster! |
