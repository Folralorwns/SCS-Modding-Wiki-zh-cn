| **1** | [![Truck_accessory_open_mod_manager.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/3.%20How%20to%20use%20truck%20accessory%20mod%20in%20game%20&%20tweak%20it/Truck_accessory_open_mod_manager.jpg)](../../../../files/Truck%20accessory%20open%20mod%20manager.jpg.md) | 打包模组后，运行游戏并进入 **模组管理器**。 |
| **2** | [![Truck_accessory_enable_mod.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/3.%20How%20to%20use%20truck%20accessory%20mod%20in%20game%20&%20tweak%20it/Truck_accessory_enable_mod.jpg)](../../../../files/Truck%20accessory%20enable%20mod.jpg.md) | 点击模组 **两次**（**1**）即可启用它，然后点击 **确认更改** 按钮（**2**）。 |
| **3** | [![Truck_accessory_enter_truck_browser.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/3.%20How%20to%20use%20truck%20accessory%20mod%20in%20game%20&%20tweak%20it/Truck_accessory_enter_truck_browser.jpg)](../../../../files/Truck%20accessory%20enter%20truck%20browser.jpg.md) | 启动档案并进入 **卡车浏览器**（**关于** (1) > **卡车浏览器** (2)） |
| **4** | [![Truck_accessory_select_renault.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/3.%20How%20to%20use%20truck%20accessory%20mod%20in%20game%20&%20tweak%20it/Truck_accessory_select_renault.jpg)](../../../../files/Truck%20accessory%20select%20renault.jpg.md) | 选择 Renault Magnum 卡车。 |
| **5** | [![Truck_accessory_select_custom_grill.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/3.%20How%20to%20use%20truck%20accessory%20mod%20in%20game%20&%20tweak%20it/Truck_accessory_select_custom_grill.jpg)](../../../../files/Truck%20accessory%20select%20custom%20grill.jpg.md) | 进入 **附加件** 菜单并选择你的配件。（如果你在创建定义文件时没有更改名称，它应称为 **CUSTOM GRILL**）。 |
| **6** | [![Truck_accessory_grill_on_truck_attempt_1.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/3.%20How%20to%20use%20truck%20accessory%20mod%20in%20game%20&%20tweak%20it/Truck_accessory_grill_on_truck_attempt_1.jpg)](../../../../files/Truck%20accessory%20grill%20on%20truck%20attempt%201.jpg.md) | 可以看到，格栅恰好位于定位点处。我们仍可以稍作调整，让它看起来更好。返回 Blender。 |
| **7** | [![Truck_accessory_adjust_position_of_mesh_and_locators.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/3.%20How%20to%20use%20truck%20accessory%20mod%20in%20game%20&%20tweak%20it/Truck_accessory_adjust_position_of_mesh_and_locators.jpg)](../../../../files/Truck%20accessory%20adjust%20position%20of%20mesh%20and%20locators.jpg.md) | 将网格和定位器稍微向下移动。 |
| **8** | [![Truck_accessory_reconvertexport.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/3.%20How%20to%20use%20truck%20accessory%20mod%20in%20game%20&%20tweak%20it/Truck_accessory_reconvertexport.jpg)](../../../../files/Truck%20accessory%20reconvertexport.jpg.md) | 在转换与打包助手窗口中关闭 **Auto Cleanup**（**1**），点击 **PACK CONVERTED DATA**（**2**），等待打包与转换结束。 |
| **9** | [![Truck_accessory_final.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/3.%20How%20to%20use%20truck%20accessory%20mod%20in%20game%20&%20tweak%20it/Truck_accessory_final.jpg)](../../../../files/Truck%20accessory%20final.jpg.md) | 再次启动游戏并进入卡车浏览器（模组已启用，因此无需再进入模组管理器），检查前格栅。如果其位置仍需改进，请从第 **6** 步开始重复所有步骤；如果位置合适，你就做出了自己的第一个卡车配件。恭喜！ |
