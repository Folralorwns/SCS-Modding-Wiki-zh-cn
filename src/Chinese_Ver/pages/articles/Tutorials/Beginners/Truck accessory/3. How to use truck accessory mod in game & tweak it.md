| **1** | [![Truck_accessory_open_mod_manager.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/3.%20How%20to%20use%20truck%20accessory%20mod%20in%20game%20&%20tweak%20it/Truck_accessory_open_mod_manager.jpg)](../../../../files/Truck%20accessory%20open%20mod%20manager.jpg.md) | After packing the mod run the game and go to the **mod manager**. |
| **2** | [![Truck_accessory_enable_mod.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/3.%20How%20to%20use%20truck%20accessory%20mod%20in%20game%20&%20tweak%20it/Truck_accessory_enable_mod.jpg)](../../../../files/Truck%20accessory%20enable%20mod.jpg.md) | Enable the mod by clicking on it **twice** (**1**) and then click **Confirm Changes** button (**2**). |
| **3** | [![Truck_accessory_enter_truck_browser.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/3.%20How%20to%20use%20truck%20accessory%20mod%20in%20game%20&%20tweak%20it/Truck_accessory_enter_truck_browser.jpg)](../../../../files/Truck%20accessory%20enter%20truck%20browser.jpg.md) | Launch the profile and go to **Truck browser** (**About** (1) > **Truck Browser** (2)) |
| **4** | [![Truck_accessory_select_renault.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/3.%20How%20to%20use%20truck%20accessory%20mod%20in%20game%20&%20tweak%20it/Truck_accessory_select_renault.jpg)](../../../../files/Truck%20accessory%20select%20renault.jpg.md) | Select the Renault Magnum truck. |
| **5** | [![Truck_accessory_select_custom_grill.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/3.%20How%20to%20use%20truck%20accessory%20mod%20in%20game%20&%20tweak%20it/Truck_accessory_select_custom_grill.jpg)](../../../../files/Truck%20accessory%20select%20custom%20grill.jpg.md) | Go to the **attachables** menu and select your accessory. (If you have not changed the name during creating definition files it should be called **CUSTOM GRILL**). |
| **6** | [![Truck_accessory_grill_on_truck_attempt_1.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/3.%20How%20to%20use%20truck%20accessory%20mod%20in%20game%20&%20tweak%20it/Truck_accessory_grill_on_truck_attempt_1.jpg)](../../../../files/Truck%20accessory%20grill%20on%20truck%20attempt%201.jpg.md) | As you can see the grill is placed right at the pin position. We can still adjust it a little bit to make it look better. Go back to Blender. |
| **7** | [![Truck_accessory_adjust_position_of_mesh_and_locators.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/3.%20How%20to%20use%20truck%20accessory%20mod%20in%20game%20&%20tweak%20it/Truck_accessory_adjust_position_of_mesh_and_locators.jpg)](../../../../files/Truck%20accessory%20adjust%20position%20of%20mesh%20and%20locators.jpg.md) | Move the mesh and locators slightly to the down. |
| **8** | [![Truck_accessory_reconvertexport.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/3.%20How%20to%20use%20truck%20accessory%20mod%20in%20game%20&%20tweak%20it/Truck_accessory_reconvertexport.jpg)](../../../../files/Truck%20accessory%20reconvertexport.jpg.md) | Switch off the **Auto Cleanup** (**1**) in conversion&pack helper window, click **PACK CONVERTED DATA** (**2**) and wait until packing and converting ends. |
| **9** | [![Truck_accessory_final.jpg](../../../../../../images/articles/Tutorials/Beginners/Truck%20accessory/3.%20How%20to%20use%20truck%20accessory%20mod%20in%20game%20&%20tweak%20it/Truck_accessory_final.jpg)](../../../../files/Truck%20accessory%20final.jpg.md) | Launch the game again go to truck browser (the mod is already enabled so you do not have to go to mod manager) again and check the front grill. If it's position still neeeds some improvement repeat everything starting from **6th** step, however if it is fine you made your first truck accessory. Congratulations! |
