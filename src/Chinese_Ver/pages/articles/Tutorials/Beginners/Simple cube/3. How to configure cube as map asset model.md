| **2** | [![Simple_cube_create_model_sii.jpg](../../../../../../images/articles/Tutorials/Beginners/Simple%20cube/3.%20How%20to%20configure%20cube%20as%20map%20asset%20model/Simple_cube_create_model_sii.jpg)](../../../../files/Simple%20cube%20create%20model%20sii.jpg.md) | 在 **world** 文件夹（**1**）内创建文件 **model.tutorials.sii**（**2**）。 |
| **3** | [![Simple_cube_simple_definition_paste.jpg](../../../../../../images/articles/Tutorials/Beginners/Simple%20cube/3.%20How%20to%20configure%20cube%20as%20map%20asset%20model/Simple_cube_simple_definition_paste.jpg)](../../../../files/Simple%20cube%20simple%20definition%20paste.jpg.md) | 用文本编辑器打开 **model.tutorials.sii** 文件，并添加以下基本定义。 SiiNunit { # For modders: Please do not modify this file if you want to add a new entry. Create in # this directory a new file "<base_name>.&lt;idofyourmod&gt;.sii" where <base_name> is name of # base file without the extension (e.g. "city" for "/def/city.sii") and &lt;idofyourmod&gt; is # some string which is unlikely to conflict with other mod. # # Warning: Even if the units are specified in more than one source file, they share the # same namespace so suffixes or prefixes should be used to avoid conflicts. model_def : model.name { model_desc: "model_path" } } |
| **4** | [![Simple_cube_change_unit_name.jpg](../../../../../../images/articles/Tutorials/Beginners/Simple%20cube/3.%20How%20to%20configure%20cube%20as%20map%20asset%20model/Simple_cube_change_unit_name.jpg)](../../../../files/Simple%20cube%20change%20unit%20name.jpg.md) | 将模型名称改为唯一的名称。出于本教程的目的，我们使用 **model.tutorials.0**，但如果你要在此处放置越来越多的模型，就必须使用不同的名称。你只需更改最后的数字，这样下一个模型将命名为 **model.tutorials.1**，再下一个为 **model.tutorials.2**，依此类推。 |
| **5** | [![Simple_cube_change_model_desc.jpg](../../../../../../images/articles/Tutorials/Beginners/Simple%20cube/3.%20How%20to%20configure%20cube%20as%20map%20asset%20model/Simple_cube_change_model_desc.jpg)](../../../../files/Simple%20cube%20change%20model%20desc.jpg.md) | 更改模型的路径。该路径就是你在上一个教程中设置的模型导出路径，再加上以 **pmd** 扩展名结尾的文件名。请注意 **pmd** 扩展名——它是在模组转换后创建的模型描述符文件格式。 <br> 然后保存文件，数据即可用于转换。你将在本教程的下一部分中学习如何操作。 |
