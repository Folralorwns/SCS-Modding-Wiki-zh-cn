Create folder called **def** in **01_simple_cube/base** folder. 2. Inside folder **def** create folder called **world**. |
| **2** | [![Simple_cube_create_model_sii.jpg](../../../../../../images/articles/Tutorials/Beginners/Simple%20cube/3.%20How%20to%20configure%20cube%20as%20map%20asset%20model/Simple_cube_create_model_sii.jpg)](../../../../files/Simple%20cube%20create%20model%20sii.jpg.md) | Inside **world** folder (**1**) create file **model.tutorials.sii** (**2**). |
| **3** | [![Simple_cube_simple_definition_paste.jpg](../../../../../../images/articles/Tutorials/Beginners/Simple%20cube/3.%20How%20to%20configure%20cube%20as%20map%20asset%20model/Simple_cube_simple_definition_paste.jpg)](../../../../files/Simple%20cube%20simple%20definition%20paste.jpg.md) | Open the **model.tutorials.sii** file with your text editor and add this basic definition. SiiNunit { # For modders: Please do not modify this file if you want to add a new entry. Create in # this directory a new file "<base_name>.&lt;idofyourmod&gt;.sii" where <base_name> is name of # base file without the extension (e.g. "city" for "/def/city.sii") and &lt;idofyourmod&gt; is # some string which is unlikely to conflict with other mod. # # Warning: Even if the units are specified in more than one source file, they share the # same namespace so suffixes or prefixes should be used to avoid conflicts. model_def : model.name { model_desc: "model_path" } } |
| **4** | [![Simple_cube_change_unit_name.jpg](../../../../../../images/articles/Tutorials/Beginners/Simple%20cube/3.%20How%20to%20configure%20cube%20as%20map%20asset%20model/Simple_cube_change_unit_name.jpg)](../../../../files/Simple%20cube%20change%20unit%20name.jpg.md) | Change name of the model to something unique. Let's use **model.tutorials.0** for this tutorial purpose however if you will put more and more models here it's must be to use different names. You can simply change the last number so next model will be called **model.tutorials.1**, another **model.tutorials.2** etc, etc. |
| **5** | [![Simple_cube_change_model_desc.jpg](../../../../../../images/articles/Tutorials/Beginners/Simple%20cube/3.%20How%20to%20configure%20cube%20as%20map%20asset%20model/Simple_cube_change_model_desc.jpg)](../../../../files/Simple%20cube%20change%20model%20desc.jpg.md) | Change path to the model. It is the export path of the model which you set in previous tutorial - plus the file name ending with **pmd** extension. Notice that **pmd** extension - it is an model descriptor file format that is created after conversion of the mod. <br> Then save the file and the data are ready to be converted. You will learn how to do that in next part of the tutorial. |
