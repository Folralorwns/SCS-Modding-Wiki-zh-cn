要为 ETS2/ATS 编辑自己的地图，你需要启动地图编辑器程序。SCS Software 提供了一个内置于游戏中的地图编辑器。在较新版本中，进入地图编辑器要容易得多。本教程将指导你启动地图编辑器以及编辑器本身的基本功能。本教程假设你使用的是 Windows 10 x64 版——但在大多数 Windows 版本上应该也能用。

|  |  |  |
| --- | --- | --- |
| **1** | [![Steam_library_game_browser.png](../../../../../../images/articles/Tutorials/Map%20Editor/Introduction%20to%20the%20Map%20Editor/Launching%20the%20Map%20Editor/Steam_library_game_browser.png)](../../../../files/Steam%20library%20game%20browser.png.md) | **找到你的 ATS/ETS2 安装目录**<br> 通常它位于： <br> *C:\Program Files (x86)\Steam\SteamLibrary\steamapps\common\American Truck Simulator\bin\win_x64\amtrucks.exe*<br> *C:\Program Files (x86)\Steam\SteamLibrary\steamapps\common\Euro Truck Simulator 2\bin\win_x64\eurotrucks2.exe*<br> <br> 你也可以通过在 Steam 库中导航到游戏来找到游戏目录 -> 右键单击游戏 -> 管理 -> 浏览本地文件 |
| **2** | [![Windows_context_menu.png](../../../../../../images/articles/Tutorials/Map%20Editor/Introduction%20to%20the%20Map%20Editor/Launching%20the%20Map%20Editor/Windows_context_menu.png)](../../../../files/Windows%20context%20menu.png.md) | 右键单击 EXE -> 发送到 > 桌面（创建快捷方式） **注意：** 你可能需要单击“显示更多选项”才能看到它 |
| **3** | [![Ets2_ats_program_properties.png](../../../../../../images/articles/Tutorials/Map%20Editor/Introduction%20to%20the%20Map%20Editor/Launching%20the%20Map%20Editor/Ets2_ats_program_properties.png)](../../../../files/Ets2%20ats%20program%20properties.png.md) | 右键单击新快捷方式 -> 属性 -> 在“目标”框中添加 `-edit` <br> **提示：** 添加 `-noworkshop` 可能更稳妥，可防止任何 Workshop 内容加载到编辑器中 <br> **提示：** 一旦你知道想编辑哪张地图，就可以改为添加 `-edit europe`，以便在 ETS2 中直接打开该地图，或在 ATS 中使用 `edit usa` |
| **4** | [![Steam_start_programs_dialog.png](../../../../../../images/articles/Tutorials/Map%20Editor/Introduction%20to%20the%20Map%20Editor/Launching%20the%20Map%20Editor/Steam_start_programs_dialog.png)](../../../../files/Steam%20start%20programs%20dialog.png.md) | 双击该图标。如果一切正常，地图编辑器应该会加载，你应能看到它。如果没有，请检查 Steam 是否因新的启动参数而要求安全验证。 |
