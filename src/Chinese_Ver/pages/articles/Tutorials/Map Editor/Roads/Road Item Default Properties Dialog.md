# 教程/地图编辑器/道路/道路项默认属性对话框

> [下一部分 →](Road%20Item%20Properties%20Dialog.md)
>
> [所有步骤](../Roads.md)

当我们选择 `Road` 项类型并按下新建项（*E 键*）时，会看到道路项默认属性对话框。在这个框中，我们可以设置道路部件的默认属性。

> **提示：** 我们可以保留这些默认设置，稍后再编辑道路属性

![Road_item_default_properties.png](../../../../../../images/articles/Tutorials/Map%20Editor/Roads/Road%20Item%20Default%20Properties%20Dialog/Road_item_default_properties.png)

|  |  |
| --- | --- |
| **道路类型** 这里是道路模型的选择 **道路着色器** 这里是道路表面材质；只有部分道路支持材质选择 **中央着色器** 道路中央部分使用的材质，即分隔式公路中间的地形；只有部分道路支持材质选择 | **道路** 默认道路模型变体 **城市道路** 城市道路模型变体 `Load Preset` 用于加载已保存的加载预设文件的按钮 |

|  |  |
| --- | --- |
| 左侧 **地形着色器** 这里是道路左侧地形材质的选择 **人行道** 道路左侧使用的人行道模型（如支持） **道路外观** 道路左侧的纹理材质选择（路面颜色）（如支持） **左边缘** 左侧道路模型与地形材质之间空间的模型选择（如支持） **道路变体** 道路左侧的道路标线种类（如支持） **右边缘** 左侧道路模型与中央着色器之间空间的模型选择（如支持） | 右侧 **地形着色器** 这里是道路右侧地形材质的选择 **人行道** 道路右侧使用的人行道模型 **道路外观** 道路右侧的纹理材质选择（路面颜色） **左边缘** 道路模型与地形材质（如适用，则为中央着色器）之间空间的模型选择 **道路变体** 道路右侧的道路标线种类 **右边缘** 道路模型与地形材质之间空间的模型选择 |
