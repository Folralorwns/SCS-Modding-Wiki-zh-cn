# 教程/地图编辑器/道路/道路节点操作

>
> [所有步骤](../Roads.md)

到目前为止，我们应该已经有一条由几个节点组成的基本道路。我们移动了道路块，让它形成漂亮的弯道，但看起来有些奇怪。如何解决这个问题？我们可以使用自由旋转来修正节点之间产生的角度，从而获得更平滑的转弯，同时还能带来一些其他独特的可能性。

|  |  |  |
| --- | --- | --- |
| **1** | [![Node_properties.jpg](../../../../../../images/articles/Tutorials/Map%20Editor/Roads/Road%20Node%20Manipulation/712px-Node_properties.jpg)](../../../../files/Node%20properties.jpg.md) | 点击节点属性（*N 键*） 点击上一个教程中道路连接最下方的节点 勾选“自由旋转”复选框 在 Yaw 框中输入 0，即 0 度 |
| **2** | [![Nice_road_curve_90d.jpg](../../../../../../images/articles/Tutorials/Map%20Editor/Roads/Road%20Node%20Manipulation/712px-Nice_road_curve_90d.jpg)](../../../../files/Nice%20road%20curve%2090d.jpg.md) | 点击最上方的节点，按同样方式操作，只是 Yaw 使用 90 度 |
| **3** | [![Road_angles_gizmo_circle.jpg](../../../../../../images/articles/Tutorials/Map%20Editor/Roads/Road%20Node%20Manipulation/712px-Road_angles_gizmo_circle.jpg)](../../../../files/Road%20angles%20gizmo%20circle.jpg.md) | 使用移动工具（*M 键*）点击节点，将道路拉直成漂亮的 90 度弯道 <br> <br> **提示：** 如果你需要进一步改善角度，可以在起点与终点节点之间添加更多节点。将鼠标悬停在红色节点上并按下鼠标中键，即可在你点击的节点与另一端（*以蓝色高亮显示*）之间创建一个新节点 <br> <br> **提示：** 试着将 `Gizmo` 切换为“圆形”，用它就能更快地画出漂亮的弯道！ |
