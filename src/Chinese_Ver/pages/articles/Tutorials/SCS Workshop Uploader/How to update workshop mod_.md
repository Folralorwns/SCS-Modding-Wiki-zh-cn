# Tutorials/SCS Workshop Uploader/How to update workshop mod?

In this tutorial you will learn how to upload an updated version of your mod to the Steam Workshop. Let's start!

## Uploading

|  |  |  |
| --- | --- | --- |
| 1 | [![Updating_mod_select_game.jpg](../../../../../images/articles/Tutorials/SCS%20Workshop%20Uploader/How%20to%20update%20workshop%20mod_/Updating_mod_select_game.jpg)](../../../files/Updating%20mod%20select%20game.jpg.md) | First of all launch SCS Workshop Uploader tool and select the game. |
| 2 | [![Updating_mod_select_item.jpg](../../../../../images/articles/Tutorials/SCS%20Workshop%20Uploader/How%20to%20update%20workshop%20mod_/Updating_mod_select_item.jpg)](../../../files/Updating%20mod%20select%20item.jpg.md) | Select the item that you want to update. |
| 3 | [![Updating_mod_adjust.jpg](../../../../../images/articles/Tutorials/SCS%20Workshop%20Uploader/How%20to%20update%20workshop%20mod_/556px-Updating_mod_adjust.jpg)](../../../files/Updating%20mod%20adjust.jpg.md) | Make sure that the folder and preview image are set to the correct paths and adjust the mod information if needed. |
| 4 | [![Updating_mod_fill_changelog.jpg](../../../../../images/articles/Tutorials/SCS%20Workshop%20Uploader/How%20to%20update%20workshop%20mod_/556px-Updating_mod_fill_changelog.jpg)](../../../files/Updating%20mod%20fill%20changelog.jpg.md) | Fill the changes. You can skip this point, however, it's always better to let mod users be informed of what you changed. |
| 5 | [![Updating_mod_click_upload.jpg](../../../../../images/articles/Tutorials/SCS%20Workshop%20Uploader/How%20to%20update%20workshop%20mod_/556px-Updating_mod_click_upload.jpg)](../../../files/Updating%20mod%20click%20upload.jpg.md) | When you have done these steps, simply click upload. In case the validator detects some problems, you will have to fix them and then start uploading again. |
