# 游戏/ATS/模组更新指南/1.5

## 建议

- 当你以原始模型为基础制作自己的模型时，也请在模组中加入该模型所使用的**所有**原始 /automat/ 文件。这些文件的名称是根据其内容生成的 SHA1 哈希值，因此每当我们以任何方式更改材质参数时，都会改用另一个文件来存储它们，而如果没有其他模型使用原始参数，原始文件可能就会消失。
- 修改原始模型时，请务必包含该模型的**所有**组件（pmg+pmd），而不仅仅是你修改过的组件。否则一旦我们更改了模型，你的模组就可能崩溃。
- 一如既往，在向支持多文件方式的文件（例如 road_look.sii）中添加新对象时，**强烈建议**在名称中使用后缀或前缀，以避免与我们在补丁中新增的对象发生冲突。否则当新补丁发布时，你可能需要使用批量重命名功能（参见批量重命名）来解决冲突。

## 如何转换地图

- 下载并安装我们的模组，用以替换被重命名的模型与变体：[链接](https://modding.scssoft.com/download/mod_load_old_map.zip)
- 加载地图
- 执行重建（F8）
- 保存地图

## 更改

### 地图

我们替换了一些预制件和预制件变体。因此，若要加载旧地图和地图模组，请下载并安装我们的模组：[链接](https://modding.scssoft.com/download/mod_load_old_map.zip)。

预制件变体更改：

- 变体 **"vineyard_01-dugheau_uzau"** 已重命名为 **"darchelle"**
- 变体 **"mining_storage-coastline_mi"** 已重命名为 **"coastmining"**

预制件模型名称更改：

- 模型 **"d_food_mkt"** 已重命名为 **"d_gen_mkt2"**
- 模型 **"d_food_mkt2"** 已重命名为 **"d_food_mkt"**
- 模型 **"d_food_mkt3"** 已重命名为 **"d_gen_mkt1"**
- 模型 **"d_food_mkt4"** 已重命名为 **"d_food_mkt1"**

### 公司数据

单元 **"company_data"** 新增属性 **"sort_name"**。它是一个字符串，用于对仅含非 ASCII 字符的公司名称进行排序。

### 气候配置

单元 **"climate_profile"** 经历了一些更改。原本简单的纬度设置已更新为完整定义的投影系统。新增属性 **"map_projection"**（默认值 **"mercator"**），通过它我们可以定义地图坐标与地球坐标之间的投影。

属性 **"latitude_a"** 与 **"latitude_b"** 已更改为 **"map_origin"** 与 **"map_factor"**。它们不再是单纯的浮点值，而是由两个浮点值构成的地球坐标向量（纬度、经度对）。基本功能与之前的纬度属性类似，但额外使用了经度，因为某些投影需要经度：

```
[latitude,longitude] = projection( map_origin + map_factor * [map_z,map_x] )
```

此外，还为 **"lambert_conic"** 投影新增了属性 **"standard_paralel_1"** 与 **"standard_paralel_2"**，该投影目前用于 ATS 重新缩放后的美国地图。所有值均以度为单位。

> **注意：** 如果你想使用旧地图，请使用 mercator 投影。此时经度完全不会被考虑，因此你可以使用任意值（最好为非零系数）。

### 车辆数据

#### 卡车数据

##### 内饰数据

单元 **"accessory_interior_data"** 新增动画——**"general_air_press_anim"** 与 **"trailer_air_press_anim"**，两者都带有各自的 **"_min"** 与 **"_max"** 值。它们是额外的气压表，目前用于 ATS 卡车 Peterbilt 389。

单元 **"accessory_interior_data"** 新增属性 **"air_brake_safeguard"**（默认值为 false 或 0）。它使驻车制动手柄变为气动式（如同美国卡车），并在气压不足时被物理弹出。因此驾驶员必须再次按下它才能行驶（这取代了欧洲卡车使用的电子开关）。
