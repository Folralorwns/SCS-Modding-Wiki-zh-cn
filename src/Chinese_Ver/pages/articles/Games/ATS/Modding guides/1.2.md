# 游戏/ATS/模组制作指南/1.2

## 建议

- 当你基于原始模型制作模型时，请同时将其中使用的**所有**原始 /automat/ 文件添加到你的模组中。文件名是根据其内容的 SHA1 哈希生成的，因此每当我们以任何方式更改材质参数时，都会用不同的文件来存储这些参数；如果没有任何其他模型沿用原始参数，原文件就可能不复存在。
- 修改原始模型时，请始终包含模型的**所有**组件（pmg+pmd），而不是只包含你更改的部分。否则一旦我们更改该模型，你就可能遇到崩溃。
- 一如既往，在向支持多文件方式的文件（例如 road_look.sii）中添加新对象时，**强烈建议**在名称中使用后缀或前缀，以避免与我们将在补丁中添加的新对象发生冲突。否则当新补丁出现时，你可能需要使用批量重命名功能（参见批量重命名）来解决冲突。

## 变更

### 定义

属性 "engine_brake_positions" 已添加至 "accessory_engine_data"。它与用于增强/减弱发动机制动的新输入配合工作，方式与缓速器相同。

若已定义，"direct_gearbox_config" 中的属性 "name" 会在游戏中显示（options/control/layout selection）。此外，属性 "name" 也添加到了 "direct_gearbox_gear"，因此每个挡位定义都可以有一个。这些名称会在游戏中显示，并覆盖 "accessory_transmission_data" 中定义的任何内容或游戏默认生成的内容。

属性 "trailer_brake_stick_anim" 和 "trailer_air_stick_anim" 已添加至 "accessory_interior_data" 单元。它们分别处理挂车制动与供气旋钮的动画。

要消除 UI 单元/定义中的警告，请从你修改过的 UI 脚本中移除以下废弃属性：child_nameless、p2p_pml、name、tooltip。

### 声音

挂车连接/断开的新声音："**/sound/truck/clunk.ogg**" 和 "**/sound/truck/clunk_off.ogg**"。

### 模型

##### 车轮定制

轮辋被拆分为 4 个配件 - disc、hub、nuts 以及可选的 hub cover。

在卡车进入升级商店之前，旧轮辋/车轮仍可正常工作。在升级商店中，已知的轮辋会被替换为新的等效项，未知的轮辋则会被替换为默认值（参见 "**/def/vehicle/rim_data.sii**"）。

所有车轮配件（车轮、轮胎、轮辋部件）都必须按稍微更严格的格式命名 - 单元名称的最后一个 token 始终定义配件的类型和位置，例如 "**rdisc**" 表示后轮的 disc。这对模组制作的 AI 车轮同样适用！以前使用的属性：front_wheel、front_rim 等现已废弃。使用的 token 名称有：玩家卡车的 "**ftire**"、"**fdisc**"、"**fhub**"、"**fnuts**" 和 "**fcover**"，以及 AI 车辆的 "**fwheel**"（后轮同理）。
