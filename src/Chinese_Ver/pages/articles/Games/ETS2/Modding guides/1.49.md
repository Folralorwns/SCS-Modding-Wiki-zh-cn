# 游戏/ETS2/模组指南/1.49

## 简介

本页面包含针对游戏新更新的模组制作指南。

为了更好地理解单元方面的改动，建议查阅[单元文档](../../../Documentation/Engine/Units.md)页面。

## 建议

- 当你以原始模型为基础制作自己的模型时，也请在模组中加入该模型所使用的**所有**原始 /automat/ 文件。这些文件的名称是根据其内容计算出的 CityHash64 哈希值，因此每当我们以任何方式更改材质参数时，都会改用另一个文件来存储它们，而如果没有其他模型使用原始参数，原始文件可能就不再存在。
- 修改原始模型时，请务必包含该模型的**所有**组件（pmg+pmd），而不仅仅是你改动过的组件。否则一旦我们更改模型，你的模组就可能崩溃。
- 一如既往，在向支持多文件方式的文件（例如 road_look.sii）中添加新对象时，**强烈建议**在名称中使用后缀或前缀，以避免与我们在补丁中新增的对象发生冲突。否则当新补丁出现时，你可能需要使用批量重命名功能（参见批量重命名）来解决冲突。

### 游戏数据

#### 损伤数据

除了可像以前一样修复的常规损伤之外，还新增了无法轻易修复的损伤（在游戏 UI 中通常称为“磨损”）。你只能通过更换车辆部件来消除它。

数据中引入了新的数值，主要是“无法修复”的数值。目前，每个可受损的部件都有“damage”和“unfixable_damage”两项统计（由碰撞造成），类似地还有“wear”和“unfixable_wear”（由行驶距离造成）。挂车也有对应的整套数值。此外还有属性 `odometer_wear_unfixable`，它是一个乘数，将自上次完全修复以来行驶的距离换算为显示的百分比。

不可修复损伤属性列表，定义碰撞造成的损伤比率：

- `cabin_unfixable_damage_ratio`
- `chassis_unfixable_damage_ratio`
- `engine_unfixable_damage_ratio`
- `transmission_unfixable_damage_ratio`
- `wheel_unfixable_damage_ratio`

持续性的不可修复磨损：

- `cabin_wear_unfixable`
- `chassis_wear_unfixable`
- `engine_wear_unfixable`
- `transmission_wear_unfixable`
- `wheel_wear_unfixable`

挂车碰撞造成的不可修复损伤比率：

- `trailer_body_unfixable_damage_ratio`
- `trailer_chassis_unfixable_damage_ratio`
- `trailer_wheel_unfixable_damage_ratio`

挂车持续性的不可修复磨损：

- `trailer_body_wear_unfixable`
- `trailer_chassis_wear_unfixable`
- `trailer_wheel_wear_unfixable`

### 车辆数据

#### 仪表盘显示 ID

仪表盘 UI 脚本新增了对 **ui_text_bar** 组件的支持，它取代了以往用于模拟条形的 2 个 **ui::text** 元素的组合。此更改的主要原因是支持同一 ID 对应多个条形。

因此现在只需定义一个 **ui_text_bar** 元素，将所有条形数据作为属性即可：

- **vertical** | *boolean* - 布尔值，决定文本元素的尺寸是按垂直方向（从下到上）还是按水平方向（从左到右）调整
- **min_size** | *integer* - 达到最小值时条形的尺寸
- **max_size** | *integer* - 达到最大值时条形的尺寸
- **min_value** | *float* - 该条形呈现最小尺寸时对应的值
- **max_value** | *float* - 该条形呈现最大尺寸时对应的值

元素示例：

```
ui_text_bar : _nameless.def_bar {
 vertical: false
 min_size: 0
 max_size: 239
 min_value: 0
 max_value: 1
 text: "<img src=/material/ui/white.mat xscale=stretch height=9px color=FFD2D2C4><ret><align vstyle=bottom><img src=/material/ui/white.mat xscale=stretch height=3px color=FFB6B5AB></align>"
 coords_l: 0
 coords_r: 239
 coords_t: 23
 coords_b: 14
 area_l: 1
 area_r: 0
 area_t: 0
 area_b: 1
 id: 1140
 layer: 2
 tab: -1
 pointer: -1
 my_parent: _nameless._.sharedisplay
}
```
