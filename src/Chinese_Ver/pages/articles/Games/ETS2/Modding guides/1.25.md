# Games/ETS2/Modding guides/1.25

## 建议

- 部分使用 "fr" 后缀或前缀的新模型仍在开发中，可能在后续某个补丁中发生显著变化。因此，建议此时避免在模组中使用它们。
- 在基于原始模型制作模型时，请将用到的**所有**原始 /automat/ 文件一并加入模组。这些文件的名称由其内容的 SHA1 哈希生成，因此每当我们以任何方式修改材质参数时，就会使用不同的文件来存储它们；如果没有其他模型使用原始参数，原始文件可能会消失。
- 修改原始模型时，务必包含模型的**所有**组件（pmg+pmd），而不是只包含你更改的部分。否则，当我们修改模型时，你可能面临崩溃风险。
- 一如既往，向支持多文件方式的文件（例如 road_look.sii）添加新对象时，**强烈建议**在名称中使用后缀或前缀，以避免与我们在补丁中新增的对象冲突。否则，当新补丁发布时，你可能需要使用批量重命名功能（见 Batch renaming）来解决冲突。

## 变更

### 游戏数据

所有依赖地图的数据已从 **game_data.sii** 移至 **map_data.sii**。请查看 **map_data.sii** 以了解废弃属性列表。

### 车辆数据

#### 方向盘调节动画

卡车内饰 **animations(_uk).sui** 新增了两个用于方向盘调节的动画。一个动画定义上/下移动，第二个定义方向盘伸缩。此外，默认属性用于说明方向盘的静止位置。

在 **/def/vehicle/truck/<your_truck_name>/interior/animations.sui** 中的示例定义：

```
wheel_updown_anim: "/vehicle/truck/<your_truck_name>/interior/<rotation_animation.pma>"
wheel_frontback_anim: "/vehicle/truck/<your_truck_name>/interior/<extension_animation.pma>"
wheel_updown_anim_default: 0.3
wheel_frontback_anim_default: 0.5
```

#### 仪表盘背光行为

卡车内饰现在包含名为 **backlight_with_lights** 的属性。它定义仪表盘是在通电（点火）时点亮，还是在灯光开启时点亮。默认值为 **true**，即灯光开启时仪表盘点亮。

#### 内饰视角查看预设

卡车内饰视角现在包含名为 **look_presets_defaults** 的数组。它是含 6 个元素的数组，定义水平面上的视角角度（单位为度）。默认值为：

```
look_presets_defaults[]: 0      // forward
look_presets_defaults[]: -40    // forward-right
look_presets_defaults[]: 20     // forward-left
look_presets_defaults[]: -70    // right
look_presets_defaults[]: 70     // left
look_presets_defaults[]: -20    // windscreen center
```

#### 方向盘配件

卡车内饰新增了名为 **steering_w** 的配件，它将方向盘定义为与内饰动画模型分离的刚性模型。模型应放在升级文件夹中：**vehicle/truck/upgrade/steering_w/<your_truck_name>**，配件定义文件必须位于：**def/vehicle/truck/<your_truck_name>/accessory/steering_w**。

方向盘配件定义文件示例：

```
SiiNunit {
accessory_addon_data : exclusive.<your_truck_brand>.<your_truck_name>.steering_w {
      name: "Exclusive Steering Wheel"
      price: 360
      unlock: 10
      icon: "<your_truck_name>/steering_w_excl"
      interior_model: "/vehicle/truck/upgrade/steering_w/<your_truck_name>/exclusive.pmd"
}
}
```

### 挂车数据

为每个挂车新增了挂车涂装。在 **/def/vehicle/trailer/<trailer_name>/** 中创建 **custom_paint_job** 并添加涂装的定义。涂装定义文件示例：

```
SiiNunit
{
accessory_paint_job_data : .paint_job
{
   airbrush: true
   alternate_uvset: true
   paint_job_mask: "<path to your tobj file>"
}
}
```

### 编辑器

新增植被与地形拾取器，便于应用相同的图案。

新增对话框，显示当前所拾取图案的信息。

### 交通

#### 生成频率

按国家划分的生成频率定义已得到改进和简化。**旧的基于文件的 (def/country/(country_name)/ai 系统现已废弃**。无需为每个车辆定义创建新文件，只需将所有自定义生成频率放入单个文件 **/def/country/(country_name)/traffic.(mod_name).sii**。

例如：

```
country_traffic_info : .country.info.traffic.a3 {
    object: traffic.a3
    spawn_frequency: 0.00
}
```

**object** —— 该信息所针对对象的单元名称；**支持所有车辆与挂车类型**

**生成频率** —— 任意非负浮点数（精度**不再被限制**为 1/10）

要在模组中覆盖某条交通信息，只需在定义文件中创建新定义，并让 **object** 属性的值与要被覆盖的定义相同。对于每个 **object**，都会使用最后加载的交通信息。

#### 速度限制

卡车的速度限制计算方式已调整。此前，**无法通过交通标志将卡车的速度限制提高到国家限制之上**。例如，城市内的卡车无论交通标志如何（如果不在高速公路/快速路这类高速道路上），都只能以较低速度行驶（例如 50 km/h）。

为消除这一限制，新增了以下属性：

**max_limit** —— 速度限制数组，定义给定车辆类型在给定国家内允许的最高速度限制值（无法被提高，例如通过交通标志）。默认情况下**不设置限制**。

作为“让卡车行驶过慢”与“允许卡车使用轿车速度限制”之间的折中，现在所有国家的卡车国家速度限制设置如下：

**对于城市中的卡车，允许通过交通标志将速度限制提高至乡村道路限速**

例如：

```
country_speed_limit : .speed_limit.truck {

    vehicle_speed_class:    truck

    lane_speed_class[]:    local_road
    limit[]:         70
    urban_limit[]:   50
    max_limit[]:     70

    lane_speed_class[]:     expressway
    limit[]:         80
    urban_limit[]:   50
    max_limit[]:     80

    lane_speed_class[]:     motorway
    limit[]:         80
    urban_limit[]:   80
    max_limit[]:     80
}
```
