# 游戏/ETS2/模组指南/1.46

## 简介

本页面包含针对游戏新更新版本的模组制作指南。

为了更好地理解单元的变化，建议查阅[单元文档](../../../Documentation/Engine/Units.md)页面。

## 建议

- 当你以原始模型为基础制作自己的模型时，也请在模组中加入该模型所使用的**所有**原始 /automat/ 文件。这些文件的名称是根据其内容生成的 CityHash64 哈希值，因此每当我们以任何方式更改材质参数时，都会改用另一个文件来存储它们，而如果没有其他模型使用原始参数，原始文件可能就会消失。
- 修改原始模型时，请务必包含该模型的**所有**组件（pmg+pmd），而不仅仅是你修改过的组件。否则一旦我们更改了模型，你的模组就可能崩溃。
- 一如既往，在向支持多文件方式的文件（例如 road_look.sii）中添加新对象时，**强烈建议**在名称中使用后缀或前缀，以避免与我们在补丁中新增的对象发生冲突。否则当新补丁发布时，你可能需要使用批量重命名功能（参见批量重命名）来解决冲突。

## 更改与新功能

### 内饰 UI 改进

卡车内饰现在对仪表盘、信息娱乐系统和配件的 UI 脚本进行统一处理。现在三种可绘制对象类型都支持所有卡车 ID。此外，信息娱乐/GPS 脚本可以像仪表盘脚本一样定义多个屏幕页面。

#### 内饰 UI 附加配件数据

有一种新的内饰配件类型，专门用于通过 UI 脚本使用自定义屏幕显示（类似于卡车仪表盘的做法）。它们使用与我们用于仪表盘和 GPS 相同的机制。有关该单元的更多信息：[此处](../../../Documentation/Engine/Units/accessory%20addon%20int%20ui%20data.md)

要创建可用的自定义 UI 配件（例如自定义 GPS），需要以下内容：

- 使用新单元类型 **accessory_addon_int_ui_data** 定义的配件，例如：

```
SiiNunit
{
accessory_addon_int_ui_data : my_gps.<brand>.<model>.<acc_type>
{
	name: "My GPS"
	price: 999
	unlock: 0
	icon: "icon_path"
	part_type: aftermarket

	interior_model: "/path/to/my_gps_model_int.pmd"
	exterior_model: "/path/to/my_gps_model_ext.pmd"

	# path to the UI script, either use custom or any existing e.g.: /ui/gps.sii
	ui_path: "/ui/gps.sii"

	# texture path for UI script to be drawn into,
	# should be unique, if it's not, then multiple scripts
	# may draw into same texture and last one to be drawn will prevail,
	# consequentially all accessories using same drawable texture path will output same result.
	ui_drawable_texture_path: "/path/to/my_gps_model_ui.tobj"

	# size of the texture UI script will be drawn into
	ui_drawable_size: (512, 256)
}
}
```

- 配件定义中的占位静态纹理，在本例中为："/path/to/my_gps_model_ui.tga" 和 "/path/to/my_gps_model_ui.tobj"
- 使用配件定义中纹理路径的材质，在本例中为："/path/to/my_gps_model_ui.tobj"
