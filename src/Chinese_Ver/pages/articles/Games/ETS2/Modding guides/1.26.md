# Games/ETS2/Modding guides/1.26

## 建议

- 在基于原始模型制作模型时，请将用到的**所有**原始 /automat/ 文件一并加入模组。这些文件的名称由其内容的 SHA1 哈希生成，因此每当我们以任何方式修改材质参数时，就会使用不同的文件来存储它们；如果没有其他模型使用原始参数，原始文件可能会消失。
- 修改原始模型时，务必包含模型的**所有**组件（pmg+pmd），而不是只包含你更改的部分。否则，当我们修改模型时，你可能面临崩溃风险。
- 一如既往，向支持多文件方式的文件（例如 road_look.sii）添加新对象时，**强烈建议**在名称中使用后缀或前缀，以避免与我们在补丁中新增的对象冲突。否则，当新补丁发布时，你可能需要使用批量重命名功能（见 Batch renaming）来解决冲突。

## 如何转换地图

- 加载地图
- 执行重建（F8）
- 保存地图

## 变更

### 公司数据

单元 **"company_data"** 新增属性 **"sort_name"**。它是一个字符串，用于对仅含非 ASCII 字符的公司名称进行排序。

### 气候配置

单元 **"climate_profile"** 发生了一些变化。原先简单的纬度设置已更新为完整定义的投影系统。新增属性 **"map_projection"**（默认值 **"mercator"**），可用于定义地图坐标与地球坐标之间的投影。

属性 **"latitude_a"** 与 **"latitude_b"** 已改为 **"map_origin"** 与 **"map_factor"**。它们不再是单纯的浮点值，而是由两个浮点值组成的地球坐标向量（纬度、经度对）。基本功能与之前的纬度属性类似，但额外使用了经度，因为某些投影需要它：

```
[latitude,longitude] = projection( map_origin + map_factor * [map_z,map_x] )
```

此外，还为目前用于重新缩放后的美国地图中 ATS 的 **"lambert_conic"** 投影新增了属性 **"standard_paralel_1"** 与 **"standard_paralel_2"**。所有数值均以度为单位。

> **注意：** 如果你想使用旧地图，请使用 mercator 投影。此时经度完全不被考虑，因此可以使用任意值（最好使用非零因子）。

### 车辆数据

#### 内饰数据

单元 **"accessory_interior_data"** 新增了动画 —— **"general_air_press_anim"** 与 **"trailer_air_press_anim"**，两者各自带有 **"_min"** 与 **"_max"** 值。它们是当前用于 ATS 卡车 Peterbilt 389 的附加气压表。

单元 **"accessory_interior_data"** 新增属性 **"air_brake_safeguard"**（默认 false 或 0）。它使驻车制动手柄变为气动式（如同美国卡车），在气压低时会被物理弹出。因此驾驶员必须再次按下它才能行驶（这取代了欧洲卡车使用的电子开关）。

#### 内饰视角

单元 **"vehicle_interior_camera"** 新增属性 **"zoom_speed"**（默认 2.5）与 **"zoom_fov_factor"**（默认 0.5）。两者都影响游戏内的即时缩放功能。
