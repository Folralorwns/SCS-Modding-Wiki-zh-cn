# 游戏/ETS2/模组指南/1.20

## 建议

- 一些使用“fr”后缀或前缀的新模型仍在开发中，很可能在后续某个补丁中发生显著变化。因此，建议你目前不要在自己的模组中使用它们。
- 当你以原始模型为基础制作模型时，请在模组中一并加入该模型所使用的**全部**原始 /automat/ 文件。文件名称由其内容的 SHA1 哈希生成，因此无论我们以何种方式修改材质参数，都会改用另一个文件来存储这些参数，如果没有其他模型使用原始参数，原文件就可能不再存在。
- 修改原始模型时，请始终包含模型的**全部**组件（pmg+pmd），而不只是你改动过的那些。否则一旦我们更改该模型，就可能引发崩溃。
- 一如既往，在向支持多文件方式（例如 road_look.sii）的文件添加新对象时，**强烈建议**在名称中使用后缀或前缀，以避免与我们在补丁中新增的对象发生冲突。否则当新补丁发布时，你可能不得不使用批量重命名功能（参见批量重命名）来修复冲突。

## 如何转换地图

- 确保日志中不含与植被配置相关的错误。以旧格式加载地图时，大部分此类信息会被烘焙进地图文件，因此在继续转换之前确保这些信息正确至关重要。
- 使用替换对话框（F3，“预制件节点校正”）来添加我们为斯堪的纳维亚部分渡轮预制件新增的预制件节点。
- 保存地图
- 执行重建（F8）
- 保存地图

## 更改

### 交通相关更改

#### AI 车辆类型定义

要指定每种车辆生成的挂车数量，请使用数组属性 **spawn_trailer_count**。它定义了给定车辆类型可用的挂车数量数组。在生成每辆 AI 车辆之前，游戏会从该数组中随机选取一个值。目前仅支持 **0** 和 **1** 两个值。例如：

```
# Set the trailer spawn probability to 75%:
#
spawn_trailer_count[]: 0
spawn_trailer_count[]: 1
spawn_trailer_count[]: 1
spawn_trailer_count[]: 1
```

目前，卡车的默认挂车生成概率为 **90%**。

#### AI 车辆定义

为了更好地控制 AI 挂车的生成，属性 **attachable_trailer** 的含义已被修改：

**之前** - 在选择要生成的挂车模型时，游戏会随机选取一个名称与数组中任一字符串匹配的模型

**现在** - 在选择要生成的挂车模型时，游戏会从数组中随机选取其中一个字符串，然后选择名称与该字符串匹配的模型。这样可以指定特定挂车模型的生成概率。此外，该属性**支持通配符 '*'**——它可以放在任意字符串的开头、任意字符串的结尾，或同时放在两者（开头和结尾），以支持挂车名称的部分匹配。

要使**所有**挂车模型都可用，请使用 `attachable_trailer[]: ""` 或 `attachable_trailer[]: "*"`

生成的挂车数量也可以通过属性 **trailer_count** 按车辆单独设置。它的工作方式与按车辆类型定义的 *spawn_trailer_count* 相同

#### AI 挂车定义

现在可以通过数组属性 **allowed_tractor** 指定每辆 AI 挂车可连接到哪些 AI 车辆。该属性**支持通配符 '*'**——它可以放在任意字符串的开头、任意字符串的结尾，或同时放在两者（开头和结尾），以支持名称的部分匹配。例如：

```
# Allow this trailer be attached only to a single vehicle

allowed_tractor[]: "traffic.scania_r_a"
```

默认情况下，所有车辆均被允许。

### 植被配置

除模型列表之外，先前存储在植被配置中的大部分信息现在改为按条目存储在地图内，以便于进行局部调整。请注意，从旧地图格式转换时，编辑器会从植被配置中提取这些信息并将其存储在地图内。从那一刻起，植被配置中的相应信息将被忽略，只会使用模型列表。

请注意，由于所存储值的精度发生变化，某些对象可能会因此轻微移动。

### 环境与天空盒

太阳配置（climate/default/nice.sii、bad.sii）不再与时间绑定，而是与太阳位置绑定。因此 **low_elevation** 和 **high_elevation** 定义了使用该配置的区间。有意义的范围为 -90 到 90 度，步长为 5 度。其工作方式与之前相同：在给定区间内，该太阳配置单独存在；超出该区间后，它开始与相邻配置混合。唯一的复杂之处是 **sun_direction**，它用于为相同高度角区分上午和下午的配置（+1 = 太阳升起 / 上午；-1 = 太阳下落 / 下午；0 = 两种情况都使用该配置）。

太阳位置根据实际时间和卡车位置计算。从地图坐标到地球坐标（即纬度）的转换公式位于气候配置（climate.sii）中，以 **latitude_a** 和 **latitude_b** 值的形式存在，因此只需选择不同的气候配置，就能在同一张地图上做出位置不同的地球区域。一些附加数据位于环境数据（env_data.sii）中——**day_in_year**（172 = 夏至）、**summer_time**（+1h）。
