# Games/ETS2/Modding guides/1.17

## 建议

- 部分使用 "sc" 后缀或前缀的新模型仍在开发中，可能在后续某个补丁中发生显著变化。因此，建议此时避免在模组中使用它们。
- 在基于原始模型制作模型时，请将用到的**所有**原始 /automat/ 文件一并加入模组。这些文件的名称由其内容的 SHA1 哈希生成，因此每当我们以任何方式修改材质参数时，就会使用不同的文件来存储它们；如果没有其他模型使用原始参数，原始文件可能会消失。
- 修改原始模型时，务必包含模型的**所有**组件（pmg+pmd），而不是只包含你更改的部分。否则，当我们修改模型时，你可能面临崩溃风险。
- 一如既往，向支持多文件方式的文件（例如 road_look.sii）添加新对象时，**强烈建议**在名称中使用后缀或前缀，以避免与我们在补丁中新增的对象冲突。否则，当新补丁发布时，你可能需要使用批量重命名功能（见 Batch renaming）来解决冲突。

## 如何转换地图

- 如果你为斯堪的纳维亚地区添加了收费站道闸，可能需要将其移除，因为它们现在由（tr_sem_mdl.ab_toll.s、tr_sem_mdl.ab_toll.dk、tr_sem_mdl.ab_toll.n）定义
- 将标志模板转换为新格式。可以手动转换，也可以使用提供的脚本。
- 我们为一些斯堪的纳维亚城市添加了渡轮，如果你的模组也通过其 **fery.<mod_id>.sii** 添加了渡轮，则需要移除冲突的添加项。
- 将粒子生成器更新为新格式。
- 保存地图
- 执行重建（F8）
- 保存地图

## 变更

### 渲染变更

我们改动了渲染，以在移动或环顾四周时提升帧率的一致性。这一改动的结果是，游戏对单个模型产生的绘制调用数量（例如部件和材质的数量）变得显著更为敏感。此外，还有一个用于存储世界几何体的固定大小缓冲区。一旦超出该缓冲区的大小，额外的绘制就会变慢。该大小默认设为 128MB，但只要你的 GPU 与驱动允许，就可以使用 r_segment_buffer_size cvar 扩展它。

### 车轮变更

车轮配件已拆分为两个独立的配件：轮胎和轮辋。

### 渡轮变更

现在可以在 /def/ferry/connection/ 内的单独文件中定义渡轮之间的连接，以获得更大的灵活性。每个文件定义一个从源渡轮到目标渡轮的连接。文件中的单元必须命名为 **conn.<source_ferry>.<target_ferry>**，并且强烈建议将相应文件命名为 **<source_ferry>_<target_ferry>.sii**

在渡轮定义中以数组方式定义连接的旧机制仍然有效。如果某个连接同时使用两种机制定义，则以新机制中的取值为准。

### 渡轮在地图上的可视化

两个渡轮之间的连接会绘制在地图上。如果定义了新的渡轮连接，就会自动在源渡轮与目标渡轮之间绘制一条直线。

出于美术目的，可以通过定义额外的曲线点，在源渡轮与目标渡轮之间定义曲线。要添加曲线点，需要在 **conn.<source_ferry>.<target_ferry>**（连接定义文件）中定义 **connection_positions[n] (int, 0, int)** 和 **connection_directions[n] (float, 0.0, float)** 字段，其中 **connection_positions** 包含不含高度的点位置，**connection_directions** 包含用于偏航角的点向量。

### 城市图钉缩放

城市图钉可在世界地图、任务地图和车库地图上缩放。要启用此功能，需要在城市定义文件中定义 **city_pin_scale_factor** 字段。

**city_pin_scale_factor[n] float** 按每个缩放级别设置 UI 地图上城市图钉与城市名称的大小。推荐值为 (0;2>；当未定义 **city_pin_scale_factor** 时，默认值同样是 1.0。地图上图钉的默认大小为 24px。

### 卡车数据变更

- 更改了仪表盘显示条的处理方式。现在不再使用控制组（ID+5），而是使用文本元素。除定义大小之外，它还保留显示条的功能数据。格式 "H~~0~~1" 表示取值从 0 到 1 的水平条。所有原先的垂直条 ID 现已不再使用。
- 向仪表盘添加了其他一些显示元素：非模态损伤警告图片（1190）、低燃油警告图片（1200）、导航距离（1210）。
- 向内饰数据添加了 `indicator_cruise_control` 动画。
- 向内饰数据添加了 `wiper_delay[]` 数组，可用于定义雨刮杆的额外中间位置及其功能（两次循环之间的延迟）。
- 向发动机数据添加了 `rpm_limit` 值。当转速高于该限制时，发动机将忽略油门。
- 从发动机数据中移除了 `motor_brake`，改为添加 `engine_brake`，作为相对制动力强度值。
- 向发动机数据添加了 `engine_brake_downshift`（默认值为 1）。它会在发动机制动激活时强制自动变速箱降档。

### 道路外观

- 已移除对属性 '**ai_lane_count**' 和 '**one_way**' 的向后兼容性
  - 如果仍在使用它们，游戏不会崩溃，只是它们的取值会被忽略
- 属性 '**no_wrong_way**' 已被属性 '**allow_wrong_way**' 取代
  - 尽管该属性在此补丁中保持向后兼容，但可能在今后的任何补丁中在不另行通知的情况下被移除
  - **allow_wrong_way** *是一个道路变体名称（作为 token）的数组，其中的车道允许逆向行驶*（即不会报告逆行违章）
  - 要允许所有变体逆向行驶，请使用包含 1 个空 token 的数组：
    - `allow_wrong_way[]: ""`

### 粒子生成器变更

- 为支持异步加载，粒子生成器现在在 particle_gen 单元中显式指定模型路径和模型外观，而不再使用 model_template 单元。你需要更新自己的定义。

### 标志模板的变更

标志模板有了新格式，具备更好的模组支持。

旧格式：

```
SiiNunit
{
sign_templates : sign_templs {
 template_paths: 2
 template_paths[0]: "/def/sign/template/sign_templ.2hw_exit_hw.sii"
 template_paths[1]: "/def/sign/template/sign_templ.3hw_noexit_h.sii"
}
}
```

New format:

```
SiiNunit
{
sign_template_def : sign_templ.2hw_exit_hw {
 path: "/def/sign/template/sign_templ.2hw_exit_hw.sii"
}
sign_template_def : sign_templ.3hw_noexit_h {
 path: "/def/sign/template/sign_templ.3hw_noexit_h.sii"
}
}
```

现在你可以在自己的模组中创建 templates.mod_xxx.sii 文件，以使用自定义的标志模板。

以前作为 **/def/sign/template/sign_templ.**.sii* 一部分的名称，现在成为 **/def/sign/templates.sii** 中模板定义单元的名称。你可以手动转换，也可以使用以下 [[PHP 脚本](http://eurotrucksimulator2.com/modding/modding_helpers_1_17.zip)] 进行转换。

### 配件隐藏标志的变更

用于控制配件在各种视图中可见性的可选标志已更改，以提升未来的可扩展性。应使用此计算器，而不要使用 1.14 模组信息中的那个。

请注意，虽然此构建中的取值与之前计算器生成的取值兼容，并且只会记录错误，但游戏的未来版本可能会改变这一点，因此你应将它们更新为新取值，以避免将来出现潜在问题。可以使用以下 [[Perl 脚本](http://eurotrucksimulator2.com/modding/modding_helpers_1_17.zip)] 来修正这些文件。
