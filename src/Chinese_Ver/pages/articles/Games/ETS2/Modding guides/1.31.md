# 游戏/ETS2/模组指南/1.31

## 建议

- 以原始模型为基础制作模型时，请在你的模组中也加入它所使用的**所有**原始 /automat/ 文件。文件名是根据其内容生成的 CityHash64 哈希，因此每当我们以任何方式更改材质参数时，都会使用另一个文件来存储它们，而如果没有其他模型使用原始参数，原始文件可能不再存在。
- 修改原始模型时，务必包含模型的**所有**组件（pmg+pmd），而不只是你更改过的部分。否则，如果我们更改了模型，你可能会遇到崩溃。
- 一如既往，向支持多文件方式（例如 road_look.sii）的文件添加新对象时，**强烈建议**在名称中使用后缀或前缀，以避免与我们在补丁中新增的对象冲突。否则，当新补丁发布时，你可能不得不使用批量重命名功能（参见批量重命名）来修复冲突。

## 如何转换地图

- 请确保在 1.30 版本中重新保存，将**所有**地图文件更新为兼容 1.30 更新的版本。否则你将无法在 1.31 编辑器中加载该地图。
- 加载地图
- 如果编辑器弹出警告对话框，提示有项引用了已废弃的 TERRAIN ONLY 道路标志，则你**必须**在保存地图之前移除或替换地图中的所有此类项。否则编辑器在加载重新保存后的地图时可能会崩溃。
- 运行预制件节点校正（F3 - “预制件节点校正”）
- 保存地图
- 执行重建（F8）
- 保存地图
- 从“Map\Validate road shoulders”运行路肩检查。这会生成所有可能对随机事件造成问题的项列表（主要是模型穿模）。你有以下选项：
  - 通过移动或删除这些项来调整它们，使其不再引发问题
  - 将相关道路标记为路肩受阻（道路项属性中的“Shoulder blocked”复选框），以阻止生成事件。
  - 如果你不在意这些问题，可以忽略该项。
- 保存地图

## 变更

### 地图格式变更

部分与道路/预制件相关的数据已从 *.base 文件移至新的 *.data 文件。

### 游戏数据

新增浮点属性 ***blinker_auto_off_trigger***（默认值为 0.01）。它用于定义在达到 ***blinker_auto_off_limit*** 而使转向灯启动之后（若已启用），转向灯自动关闭的精确时刻。

### 国家数据

新增布尔属性 ***trailer_standalone***（默认值为 false）。它用于挂车没有独立登记、而是与卡车或类似车辆一同登记并因此共用其车牌的国家（例如英国）。

### 车辆数据

#### 底盘配件数据

[底盘数据](../../../Documentation/Engine/Units/accessory%20chassis%20data.md) 中新增了数组属性 ***steerable_axle[]***。它取代定位器名称，用于控制哪些车轴可转向。现在定位器名称仅用于定义车轮类型（模型）的依赖关系。***steerable_axle[]*** 的语义与 ***powered_axle[]*** 或 ***liftable_axle[]*** 相同。若未定义，则根据车辆类型推断其值。默认情况下，挂车没有可转向车轴，而卡车的第一轴可转向。

定义驱动轮时不再支持 ***powered_wheel[]*** 数组，该数组现已被忽略。现在必须正确使用 ***powered_axle[]*** 数组。

#### 新增的线缆配件数据

随着挂车线缆这一新功能的推出，还新增了配件类型 **accessory_addon_trailer_cables_data**，可用于卡车和挂车（用于双挂、三挂等）。该配件类型只能与名为 **trlr_cables** 的配件配合使用。

这种新配件类型除常规车辆配件属性外，还具有一个类型为 **physics_trailer_cable_data** 的所有者指针数组属性。该数组定义车辆上将使用哪些种类以及多少根线缆。数组中的每个线缆指针都必须在同一个 SiiNunit 内定义。

挂车线缆配件数据示例：

```
SiiNunit
{
accessory_addon_trailer_cables_data : stock.<vehicle.name>.trlr_cables
{
	exterior_model: "<path/to/upgrade/model.pmd>"

	cables[]: .air_cable_b
	cables[]: .air_cable_r
	cables[]: .ele_cable_g
}

physics_trailer_cable_data : .air_cable_b
{
	locator_prefix: air_cable_b       // Name of the locator (in vehicle and trailer) where cable will be "connected".
	rest_locator_prefix: rst_cable_b  // Name of the locator (in vehicle only) where cable will be put to rest, when not connected to the trailer.
                                          // If not present in vehicle, cable is not visible when disconnected from trailer.

	vehicle_plug_model: "/vehicle/share/models/cables_connectors/air_plug_b.pmd"    // Plug model for the cable end on vehicle side.
	vehicle_plug_model_offset: (-0.0205, 0.0, -0.121)                               // Visual offset of cable start in space of vehicle plug model.
	trailer_plug_model: "/vehicle/share/models/cables_connectors/air_socket_b.pmd"  // Plug model for the cable end on trailer side.
	trailer_plug_model_offset: (0.0, 0.0, -0.11)                                    // Visual offset of cable end in space of trailer plug model.

	ring_count: 10      // Number of rings in spiral of cable.
	ring_resolution: 7  // Resolution of the ring, how many sides each ring has.
	diameter: 0.9       // Diameter of spiral.
	width: 0.0175       // Width of the cable itself.

	material: "/material/ropes/cable_white.mat"  // Material used for cable rendering.
	color: (0.1, 0.35, 0.55)                     // Vertex color that will be used for the cable. Note that this color is in linear colorspace.
}

physics_trailer_cable_data : .air_cable_r
{
	locator_prefix: air_cable_r
	rest_locator_prefix: rst_cable_r

	vehicle_plug_model: "/vehicle/share/models/cables_connectors/air_plug_r.pmd"
	vehicle_plug_model_offset: (-0.0205, 0.0, -0.121)
	trailer_plug_model: "/vehicle/share/models/cables_connectors/air_socket_r.pmd"
	trailer_plug_model_offset: (0.0, 0.0, -0.11)

	ring_count: 10

	color: (0.5, 0.05, 0.05)
}

physics_trailer_cable_data : .ele_cable_g
{
	locator_prefix: ele_cable_g
	rest_locator_prefix: rst_cable_g

	vehicle_plug_model: "/vehicle/share/models/cables_connectors/electric_plug.pmd"
	vehicle_plug_model_offset: (0.0, 0.0, -0.134)

	ring_count: 10

	color: (0.1, 0.1, 0.1)
}

}
```

#### 卡车数据

##### 变速箱配件数据

新增浮点属性 ***shift_time***。其值为换挡的近似持续时间（单位：秒），默认值为 1.0。该时间从离合器开始分离的那一刻计起，直到离合器再次完全接合为止。根据我们的精确测量，目前大多数变速箱的换挡时间在 0.7 秒（新款 Opticruise）到 1.5 秒（旧款 MP3 变速箱）之间。差异过大的取值可能会引发意外效果。

##### 卡车经销商数据

卡车经销商中的卡车不再通过列表处理，游戏会以与公司卡车或桌面卡车相同的方式读取给定目录中的所有单元文件。列表文件已被移除，卡车文件必须是独立的单元（以 SiiNunit 头开始，并正确用花括号括起）。目录中损坏的单元不会影响其余文件的读取。
