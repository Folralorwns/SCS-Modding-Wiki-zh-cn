# Documentation/Tools/SCS Workshop Uploader/FAQ

- 问：我想把地图模组上传到创意工坊，但收到大量错误提示称 .aux 及其他文件格式不受支持。求助！
- 答：在 Steam 创意工坊实现的初始版本中，我们不支持地图模组。未来可能会提供支持。

- 问：我想创建类型为 X 的模组，但没有看到可用的该类型标签。该怎么办？
- 答：我们建议使用 “Others” 标签。不过，我们会逐步添加新的标签。

- 问：游戏已更新，我的模组不再工作。我怎样才能向处于不同版本的用户提供模组的多个版本？
- 答：Steam 创意工坊模组允许你同时支持多个游戏版本。点击[此处](Workshop%20mod%20structure.md)了解具体做法。

- 问：我想更新我的模组。该怎么做？
- 答：打开 SCS Workshop Uploader 后，你即可选择游戏及你已发布的模组。只需选择模组文件夹与图片，并撰写更新日志。像首次上传那样点击 “Upload”，你的模组便会自动分发给所有订阅者。点击[此处](../../../Tutorials/SCS%20Workshop%20Uploader/How%20to%20update%20workshop%20mod_.md)了解更多。
