# Documentation/Tools/Font Generator/Download

提供对生成游戏字体文件的支持。请参见附带的示例文件。

- 对于 1.43 及以上的游戏版本，请使用[此版本](https://download.eurotrucksimulator2.com/fontgen_211223.zip)。
- 对于更旧的游戏版本，请使用[此版本](https://download.eurotrucksimulator2.com/fontgen_190425.zip)。

1.43+ 字体渲染系统的文档见[此处](../../Engine/Fonts.md)。
