# 文档/工具/地图编辑器/ATS 地图重缩放

新版重缩放 ATS 地图的编辑器背景图可从[此处](https://modding.scssoft.com/download/new_usa_editor_bcg.zip)下载。

请注意，要在编辑器中使用，需要将图像从 jpg 转换为 dds（或 tga）。编辑器数据文件包含地图在空间中的位置信息。
