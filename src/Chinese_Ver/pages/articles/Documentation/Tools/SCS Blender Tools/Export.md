# 文档/工具/SCS Blender Tools/导出

除了从 [导出面板](Export%20Panel.md) 导出模型外，你还可以从菜单项 **SCS Game Object(s) (.pim)** 导出模型。它的行为与导出面板相同，区别在于所有文件都会导出到所选目录中。

[![SCS_Tools_Export_02.280.png](../../../../../../images/articles/Documentation/Tools/SCS%20Blender%20Tools/Export/SCS_Tools_Export_02.280.png)](../../../../files/SCS%20Tools%20Export%2002.280.png.md)

> > **注意：** 即使可以选择不同的目录，该目录仍必须位于当前的 SCS Project Base Path 内，否则将无法重建相对纹理路径。

## 导出选项

[![SCS_Tools_Export_03.280.png](../../../../../../images/articles/Documentation/Tools/SCS%20Blender%20Tools/Export/SCS_Tools_Export_03.280.png)](../../../../files/SCS%20Tools%20Export%2003.280.png.md)

这里的第一个选项涵盖导出范围，你可以在全部三种导出范围类型之间选择，与 [导出面板#导出模式（范围）](Export%20Panel.md#Export_modes_(Scope)) 中类似。

**Export Scale** - 参见 [导出面板#其他导出选项](Export%20Panel.md#Other_export_options) 章节

**Apply Modifiers** - 参见 [导出面板#其他导出选项](Export%20Panel.md#Other_export_options) 章节

**Apply Only 'Edge Split' Modifier** - 参见 [导出面板#其他导出选项](Export%20Panel.md#Other_export_options) 章节

**Output Format** - 参见 [导出面板#其他导出选项](Export%20Panel.md#Other_export_options) 章节
