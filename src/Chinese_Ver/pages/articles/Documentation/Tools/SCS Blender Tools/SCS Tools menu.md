# 文档/工具/SCS Blender Tools/SCS Tools 菜单

![SCS_Tools_Main_Menu.280.png](../../../../../../images/articles/Documentation/Tools/SCS%20Blender%20Tools/SCS%20Tools%20menu/300px-SCS_Tools_Main_Menu.280.png)

SCS Blender Tools 由各类操作符、面板和菜单组成。要快速访问甚至搜索任何操作或属性，你可以使用 Blender 顶栏中的 **SCS Tools** 菜单。该菜单为执行与 SCS 对象及全局设置相关的操作提供了另一种途径。对于新手，以及喜欢从单一主菜单访问所有功能的人来说，使用该菜单会非常有帮助。

菜单分为若干类别。

### 添加与杂项操作符

用于添加新 SCS 对象的菜单（通常通过 `⇧ Shift` + `A` 访问的菜单），以及通常只能通过 [*"Operator Search.." 菜单*](https://docs.blender.org/manual/en/latest/interface/controls/templates/operator_search.html) 访问的杂项操作菜单，

### 侧边栏工具

供 3D 视图使用的工具（通常通过 3D 视图侧边栏访问：[SCS Tools 侧边栏](SCS%20Tools%20Sidebar.md)），

### 属性

来自 Blender 属性窗口不同选项卡的弹出面板，你可以在其中访问 SCS Blender Tools 从 [全局设置](Global%20Settings.md) 到所有可能的对象设置、[材质](Materials.md) 设置等各项设置，

### 输出管理

来自 Blender 属性窗口 Output 选项卡的弹出面板，你可以在其中管理或执行导出与转换。
