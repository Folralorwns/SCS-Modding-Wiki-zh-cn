# 文档/引擎/游戏用户路径

所有 SCS 游戏和专用服务器都在用户主目录中拥有各自的用户路径。它用于存储/读取：游戏设置、专用服务器设置、游戏配置文件、模组、音乐和屏幕截图。

游戏用户路径的位置因平台而异：

- Windows：<br><code>C:\Users\&lt;your_user_name&gt;\Documents\&lt;game_name&gt;</code>

> **注意：** 在使用 Windows 10 与 OneDrive 的情况下，路径为 `C:/Users/<your_user_name>/OneDrive/Documents/<game_name>`

- Linux：<br><code>/home/&lt;user_name&gt;/.local/share/&lt;game_name&gt;</code>
- Mac OS X：<br><code>/Users/&lt;your_user_name&gt;/Library/Application Support/&lt;game_name&gt;</code>
