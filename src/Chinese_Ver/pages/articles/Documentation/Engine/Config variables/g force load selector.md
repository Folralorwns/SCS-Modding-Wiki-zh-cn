# Documentation/Engine/Config variables/g force load selector

|  |  |
| --- | --- |
| **名称：** | g_force_load_selector |
| **用途：** | 强制显示读取存档槽位选择器。 |
| **配置：** | profile |
| **取值：** | 整数 - load_selector |

## load_selector 取值：

| 取值 | 说明 |
| --- | --- |
| -1 | 作为崩溃检测的一部分自动启用 |
| 0 | 禁用 |
| 1 | 启用 |
