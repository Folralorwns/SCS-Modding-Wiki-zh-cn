# Documentation/Engine/Config variables/r deferred debug

|  |  |
| --- | --- |
| **名称：** | r_deferred_debug |
| **用途：** | 设置延迟渲染器调试模式。 |
| **配置：** | global |
| **取值：** | 整数 - debug_mode |

## debug_mode 取值：

| 取值 | 名称 |
| --- | --- |
| 0 | 调试已禁用 |
| 1 | 位置 |
| 2 | 法线 |
| 3 | 漫反射 |
| 4 | 镜面反射 |
| 5 | 阴影强度 |
| 6 | 高光强度 |
| 7 | 附加环境光 |
| 8 | 环境贴图权重 |
| 9 | 混合状态 |
| 10 | 光照漫反射 |
| 11 | 光照镜面反射 |
| 12 | 光照环境贴图强度 |
| 13 | HDR 合成 |
| 14 | LDR 合成 |
| 15 | 畸变 |
| 16 | MLAA 权重 |
| 17 | 太阳光束遮罩 |
