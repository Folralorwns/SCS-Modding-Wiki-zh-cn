# Documentation/Engine/Config variables/r multimon mode

|  |  |
| --- | --- |
| **名称：** | r_multimon_mode |
| **用途：** | 控制多显示器模式。 |
| **配置：** | global |
| **取值：** | 整数 - multimon_mode |

## multimon_mode 取值：

| 取值 | 说明 |
| --- | --- |
| 0 | 禁用 |
| 1 | 三台等宽显示器，单一视图（UI 位于中央显示器） |
| 2 | 三台等宽显示器，各自独立视图 |
| 3 | 四台等宽显示器，三个独立主视图和一个朝向仪表盘的辅助视图 |
| 4 | 自定义布局配置 |
