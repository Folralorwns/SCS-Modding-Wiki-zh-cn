# Documentation/Engine/Config variables/g parking difficulty

|  |  |
| --- | --- |
| **名称：** | g_parking_difficulty |
| **用途：** | 泊车难度设置。 |
| **配置：** | profile |
| **取值：** | 整数 - difficulty |

正确的取值如下：

| 取值 | 说明 |
| --- | --- |
| 0 | 无（到达目的地公司时显示选择对话框） |
| 1 | 简单 |
| 2 | 中等或困难 |
| 3 | 随机 |
