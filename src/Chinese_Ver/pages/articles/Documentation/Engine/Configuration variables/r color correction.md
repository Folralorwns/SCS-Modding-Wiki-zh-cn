# Documentation/Engine/Configuration variables/r color correction

|  |  |
| --- | --- |
| **名称：** | r_color_correction |
| **用途：** | 色彩校正状态。 |
| **配置：** | global |
| **取值：** | integer - correction_state |

## correction_state 取值：

| 取值 | 描述 |
| --- | --- |
| 0 | 禁用 |
| 1 | 启用，使用游戏数据 |
| 2 | 启用，使用 cvar 值 r_color_* |
