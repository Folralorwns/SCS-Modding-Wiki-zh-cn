# Documentation/Engine/Configuration variables/g cargo sort

|  |  |
| --- | --- |
| **名称：** | g_cargo_sort |
| **用途：** | 当前货物排序方式。 |
| **配置：** | global |
| **取值：** | 整数 - sort_method |

## sort_method 取值：

| 取值 | 说明 |
| --- | --- |
| 0 | 按价格降序排序。 |
| 1 | 按价格升序排序。 |
| 2 | 按价格/km 降序排序。 |
| 3 | 按价格/km 升序排序。 |
| 4 | 按到期时间升序排序。 |
| 5 | 按到期时间降序排序。 |
| 6 | 按起点升序排序。 |
| 7 | 按起点降序排序。 |
| 8 | 按目的地升序排序。 |
| 9 | 按目的地降序排序。 |
| 10 | 按路线长度升序排序。 |
| 11 | 按路线长度降序排序。 |
| 12 | 按重量升序排序。 |
| 13 | 按重量降序排序。 |
| 14 | 按来源公司升序排序。 |
| 15 | 按来源公司降序排序。 |
| 16 | 按目标公司升序排序。 |
| 17 | 按目标公司降序排序。 |
