# 文档/引擎/配置变量/g online loading screens

|  |  |
| --- | --- |
| **名称：** | g_online_loading_screens |
| **用途：** | 是否启用在线加载画面？ |
| **配置：** | global |
| **值：** | integer - online_loadings_state |

## online_loadings_state 取值：

| 值 | 说明 |
| --- | --- |
| -1 | 由用户决定 |
| 0 | 已禁用 |
| 1 | 已启用 |
