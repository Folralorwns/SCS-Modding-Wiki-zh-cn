# 文档/引擎/配置变量/g rain reflection

|  |  |
| --- | --- |
| **名称：** | g_rain_reflection |
| **用途：** | 雨水反射质量。 |
| **配置：** | global |
| **值：** | integer - reflection_quality |

## reflection_quality 取值：

| 值 | 说明 |
| --- | --- |
| 0 | 无反射 |
| 1 | 立方体反射 |
| 2 | 平面反射并带淡出 |
| 3 | 平面反射并与立方体反射交叉淡化 |
