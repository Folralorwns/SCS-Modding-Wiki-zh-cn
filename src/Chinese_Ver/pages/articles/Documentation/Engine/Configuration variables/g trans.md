# Documentation/Engine/Configuration variables/g trans

|  |  |
| --- | --- |
| **名称：** | g_trans |
| **用途：** | 变速箱类型。 |
| **配置：** | profile |
| **取值：** | integer - trans_type |

## trans_type 取值：

| 取值 | 描述 |
| --- | --- |
| 0 | 街机（自动换挡 + 自动倒挡） |
| 1 | 顺序换挡 |
| 2 | H 型换挡 |
| 3 | 自动换挡 |
