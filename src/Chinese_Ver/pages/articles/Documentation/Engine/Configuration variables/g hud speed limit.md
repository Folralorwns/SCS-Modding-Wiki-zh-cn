# 文档/引擎/配置变量/g hud speed limit

|  |  |
| --- | --- |
| **名称：** | g_hud_speed_limit |
| **用途：** | 路线顾问上的限速状态。 |
| **配置：** | profile |
| **值：** | integer - speed_limit |

## speed_limit 取值：

| 值 | 说明 |
| --- | --- |
| 0 | 隐藏 |
| 1 | 显示卡车限速 |
| 2 | 显示轿车/通用限速 |
