# 文档/引擎/配置变量/g reflection

|  |  |
| --- | --- |
| **名称：** | g_reflection |
| **用途：** | 反射细节。 |
| **配置：** | global |
| **值：** | integer - reflection_detail |

## reflection_detail 取值：

| 值 | 说明 |
| --- | --- |
| 0 | 无反射 |
| 1 | 仅水面反射 |
| 2 | 仅车辆反射 |
| 3 | 水面与车辆反射均启用 |
