# Documentation/Engine/Configuration variables/g steam screenshots

|  |  |
| --- | --- |
| **名称：** | g_steam_screenshots |
| **用途：** | 在 Steam 版本中处理截图的方式。 |
| **配置：** | global |
| **取值：** | integer - handle_way |

## handle_way:

| 取值 | 描述 |
| --- | --- |
| 0 | 不做特殊处理。 |
| 1 | 游戏拍摄的截图也会添加到 Steam |
| 2 | 由游戏完全接管 Steam 截图的捕获 |
