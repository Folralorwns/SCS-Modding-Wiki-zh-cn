# 文档/引擎/配置变量/g hshifter layout

|  |  |
| --- | --- |
| **名称：** | g_hshifter_layout |
| **用途：** | hshifter 布局的类型。 |
| **配置：** | profile |
| **值：** | integer - hshifter_layout |

## hshifter_layout 取值：

| 值 | 说明 |
| --- | --- |
| 0 | 范围档 |
| 1 | 半档 |
| 2 | 范围档加半档 |
