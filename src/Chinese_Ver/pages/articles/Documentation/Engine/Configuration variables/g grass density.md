# 文档/引擎/配置变量/g grass density

|  |  |
| --- | --- |
| **名称：** | g_grass_density |
| **用途：** | 草地密度设置。 |
| **配置：** | global |
| **值：** | integer - grass_density |

## grass_density 取值：

| 值 | 说明 |
| --- | --- |
| 0 | 关闭 |
| 1 | 低 |
| 2 | 中（在 UI 中为高） |
| 3 | 高（UI 中不可用，请勿在 32 位版本中使用） |
