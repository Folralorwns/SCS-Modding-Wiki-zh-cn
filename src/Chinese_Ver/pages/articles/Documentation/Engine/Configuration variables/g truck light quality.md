# Documentation/Engine/Configuration variables/g truck light quality

|  |  |
| --- | --- |
| **名称：** | g_truck_light_quality |
| **用途：** | 前照灯效果的质量。 |
| **配置：** | global |
| **取值：** | integer - truck_light_quality |

## truck_light_quality 取值：

| 取值 | 描述 |

| 0 | 单一光源，配两个遮罩 |
| 1 | 两个独立光源 |
