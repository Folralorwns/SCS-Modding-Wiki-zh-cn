# 文档/引擎/配置变量/g news

|  |  |
| --- | --- |
| **名称：** | g_news |
| **用途：** | 是否启用在线新闻？ |
| **配置：** | global |
| **值：** | integer - online_news_state |

## online_news_state 取值：

| 值 | 说明 |
| --- | --- |
| -1 | 由用户决定 |
| 0 | 已禁用 |
| 1 | 已启用 |
