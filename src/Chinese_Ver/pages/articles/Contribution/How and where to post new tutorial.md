# Contribution/How and where to post new tutorial

Before being able to post a tutorial on this wiki, you have to apply to make contributions (check the main [Contribution](../Contribution.md) page for more details).

Once you have ability to post a tutorial, you have to create new page(s) and populate it with content of your tutorial:

1. Depending on the scope of the tutorial decide in which category you will put the tutorial: : Let's say we pick category: "Advanced"
  1. [Tutorials/Beginners](../Tutorials/Beginners.md) - if you have complete tutorial for creation of the mod from zero to final working mod package.
  2. [Tutorials/Advanced](../Tutorials/Advanced.md) - if you have tutorial describing more particular mod creation or game configuration for example: "How to create your own shifter layout" or "How to alter animation for truck & use it in game".
  3. [Tutorials/SCS Blender Tools](../Tutorials/SCS%20Blender%20Tools.md) - if you have tutorial which uses mostly or only SCS Blender Tools, like: "How to setup light mask for a truck" or "How to setup & export multiple SCS Game Objects".
  4. [Tutorials/SCS Workshop Uploader](../Tutorials/SCS%20Workshop%20Uploader.md) - if you have tutorial for SCS Workshop Uploader application usage.
  5. [Tutorials/Map Editor](../Tutorials/Map%20Editor.md) - if you have tutorial for Map Editor usage.
2. Decide what will be title of your tutorial. Let's say our tutorial name will be: "My tutorial"
3. Create main tutorial page by typing URL into address bar: "***modding.scssoft.com/wiki/Tutorials/&lt;category&gt;/<my_tutorial_name>***" and then click on "***Create***" tab (placed on top-right part of the page). So our case that would be typing in URL: "modding.scssoft.com/wiki/Tutorials/Advanced/My tutorial" and then using "*Create*" button.
4. Now depending on your tutorial you have two options:
  1. For tutorial which will be separated into more parts, use contents of [User tutorial template (divided to parts)](User%20tutorial%20template%20(divided%20to%20parts).md) and also create tutorial parts subpages like in given template.
  2. For tutorial in one piece, use contents of template page: [User tutorial template](User%20tutorial%20template.md) and no extra subpage creation is needed.
