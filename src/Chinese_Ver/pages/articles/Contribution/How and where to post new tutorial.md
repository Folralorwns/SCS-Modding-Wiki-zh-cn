# 贡献/如何以及在何处发布新教程

在此 wiki 上发布教程之前，你必须先申请参与贡献（更多详情请查看主 [贡献](../Contribution.md) 页面）。

一旦你具备了发布教程的权限，你就需要创建新页面，并在其中填入教程的内容：

1. 根据教程的范围，决定将教程放入哪个分类：假设我们选择分类：“Advanced”
   1. [教程/入门](../Tutorials/Beginners.md) - 如果你拥有从零开始制作模组、直到生成最终可用模组包的完整教程。
   2. [教程/进阶](../Tutorials/Advanced.md) - 如果你的教程描述的是更具体的模组制作或游戏配置，例如：“如何创建你自己的换挡杆布局”或“如何修改卡车的动画并在游戏中使用它”。
   3. [教程/SCS Blender Tools](../Tutorials/SCS%20Blender%20Tools.md) - 如果你的教程主要或仅使用 SCS Blender Tools，例如：“如何为卡车设置灯光遮罩”或“如何设置并导出多个 SCS Game Objects”。
   4. [教程/SCS Workshop Uploader](../Tutorials/SCS%20Workshop%20Uploader.md) - 如果你的教程介绍 SCS Workshop Uploader 应用程序的使用。
   5. [教程/地图编辑器](../Tutorials/Map%20Editor.md) - 如果你的教程介绍地图编辑器的使用。
2. 确定你的教程标题。假设我们的教程名称为：“My tutorial”
3. 在地址栏中输入 URL 来创建教程主页面：“***modding.scssoft.com/wiki/Tutorials/&lt;category&gt;/<my_tutorial_name>***”，然后点击“***Create***”选项卡（位于页面右上部分）。因此在本例中，需要在 URL 中输入：“modding.scssoft.com/wiki/Tutorials/Advanced/My tutorial”，然后使用“*Create*”按钮。
4. 现在，根据你的教程情况，你有两个选择：
   1. 对于将拆分为多个部分的教程，使用 [用户教程模板（分为多个部分）](User%20tutorial%20template%20(divided%20to%20parts).md) 的内容，并像给定模板中那样创建教程各部分的子页面。
   2. 对于单篇完整教程，使用模板页面 [用户教程模板](User%20tutorial%20template.md) 的内容，无需创建额外的子页面。
