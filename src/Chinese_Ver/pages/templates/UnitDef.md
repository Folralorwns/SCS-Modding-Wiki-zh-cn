# Template:UnitDef

This template simplifies inclusion of raw unit structures on their wikipage by applying standard formatting. The result is a collapsible section with a 300px-tall, scrollable preformatted text section. For best results, use **&lt;nowiki&gt;** tags to prevent double-braces from prematurely closing the template: `{{UnitDef|def=<nowiki>def</nowiki>}}`

## Raw Unit Definition

```
{{{def}}}
```
