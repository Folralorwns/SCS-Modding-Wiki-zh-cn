## Game Archive Extractor 的变更

你好！我想讨论一下你的这次改动（[http://modding.scssoft.com/index.php?title=Documentation/Tools/Game_Archive_Extractor&diff=2697](http://modding.scssoft.com/index.php?title=Documentation/Tools/Game_Archive_Extractor&diff=2697)）。遗憾的是，从我们看到的情况来看，它并不完全正确。

```
You may also click and drop the .SCS file (#1) onto the SCS Extractor to extract the files. For example drag the base.scs file onto the SCS Extractor. This will then extract all the containing files into the current location. (#2) You should do this in a separate folder to keep files tidy, just copy the Base.scs #3 file (for example) into a separate folder along with the scs extractor and then follow the above instruction.
```

1. .SCS 的“文件”其实是归档包，所以最好用“归档包”而不是“文件”。另外，在代码标签中直接写 `.scs` 会更好，这样它就会是 `.scs`。
2. 我会把它放进提示中。
3. 如果你提到某个文件名，它应该是正确的——不是 `Base.scs`，而是 `base.scs`——另外文件名应该用代码标签包裹，所以应该是 `base.scs` 而不是 base.scs。
